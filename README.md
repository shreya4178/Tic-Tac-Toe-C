# 🎮 Tic-Tac-Toe in C

A console-based Tic-Tac-Toe game developed using **C programming** as a beginner-level programming project.

## 📌 About the Project

This is a two-player Tic-Tac-Toe game where:

- Player 1 uses **X**
- Player 2 uses **O**
- Players choose positions from **1 to 9**
- The game checks for a winner after every move
- Invalid and already occupied positions are handled
- The game also detects a draw

## 🛠️ Concepts Used

- C Programming
- Variables and Data Types
- Arrays
- Functions
- Loops
- Conditional Statements
- User Input
- Basic Game Logic

## 🎯 Features

- Two-player gameplay
- 3×3 game board
- Win detection
- Draw detection
- Invalid position validation
- Occupied position validation
- Simple console interface
